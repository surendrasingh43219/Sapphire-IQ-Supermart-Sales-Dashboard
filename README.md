# 🛒 Sapphire IQ Supermart Grocery Sales Dashboard

## 📌 Project Overview

The **Sapphire IQ Supermart Grocery Sales Dashboard** is an Excel-based data analytics project designed to analyze grocery sales, profit, product performance, discount patterns, and geographic sales distribution.

The dashboard transforms raw CSV sales data into meaningful business insights using Excel charts, KPI cards, and summary tables. It helps users understand sales trends, identify high-performing product categories, and evaluate regional performance.

## 🎯 Project Objectives

- Analyze total sales and total profit.
- Identify the highest-performing product categories and sub-categories.
- Understand monthly sales trends.
- Compare sales and profit across regions.
- Identify cities with the highest sales.
- Analyze the relationship between discounts and profit.
- Present business insights through a visual Excel dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Excel** — Dashboard creation and data analysis
- **CSV** — Source dataset
- **Excel Charts** — Data visualization
- **Excel Formulas** — Sales and profit calculations
- **Data Analytics** — Business performance analysis

## 📂 Dataset Information

The project uses a Supermart Grocery Sales dataset containing **9,994 sales records**.

The dataset includes fields such as:

- Order ID
- Customer Name
- Category
- Sub Category
- City
- Order Date
- Region
- Sales
- Discount
- Profit
- State

The dataset is used to analyze sales performance, product categories, profitability, and geographic trends.

## 🔍 Limitations

- The analysis depends on the accuracy and completeness of the source dataset.
- Geographic conclusions are limited to the locations available in the data.
- A relationship between discount and profit does not necessarily establish causation.
- The dashboard is built in Excel and is not automatically connected to a live sales database.
